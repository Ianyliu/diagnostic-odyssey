# Diagnostic Odyssey · Strategy Lab

An **isolated, static design experiment** in apps/strategy-lab, combining interaction patterns from six supplied strategy-dashboard mockups. It does not replace the production web app, modify the scientific pipelines, or write to the canonical planning brief.

## Run

Open index.html through a local static HTTP server (for example, Python's http.server from this directory) or deploy this directory as a static Vercel project. It uses only browser-native HTML, CSS, SVG and JavaScript modules; no runtime API calls or external JavaScript dependencies.

## Scope and provenance

- Brief: proactive strategic summary and explicit evidence/assumption/gap distinctions.
- Terrain: browseable drivers and the schematic evidence-to-decision Sankey.
- Investigations: dossiers with questions that could reverse a recommendation.
- Moves: alternative pilots, trade-offs, and bounded arithmetic assumptions.
- War Room: a planning board and interactive feasibility checks (not predicted intervention effects).
- Decision Record: draft deliberation, export JSON and decision trace.

All modelled scenarios are **fictional planning examples**, not evaluations of pilot efficacy, cost saving, clinical benefit, patient outcomes, or actual local operations. A source-count label references the project's public README (21 reviewed national MEPS estimates, 34 WV context indicators, 2 descriptive Typical Ranges); the demonstration never treats these as compatible numerical flow quantities. No personal health information is collected; notes stay in memory until page refresh.

## Deliberate separation

This directory is a proof-of-concept. Do not attach it to production data, implement unreviewed effects, overwrite canonical briefs, or merge it into main without separate design, scientific, accessibility and security review.
