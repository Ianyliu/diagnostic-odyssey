# ME/CFS compatibility proof

ME/CFS is a partial compatibility target, not a second fully implemented burden model.

The architecture may reuse:
- core contracts;
- release/display states;
- evidence records;
- pathway/scenario abstractions;
- graceful-degradation behavior.

It must **not** reuse Long COVID values as ME/CFS estimates. Unavailable economic bridges remain unavailable until supported by appropriate data/methods.
